# WCD — Waqt Cut Daalo ⏱

**Bore ho rahe ho? Ek button dabao, ek fun task pao — 5 minute me boredom gayab!**

WCD ek simple, fun web app hai jo aapko time-pass karne ke liye random tasks deta hai —
masti, creative challenges, dimag ke khel, fitness bursts, dares aur kuch naya seekhne wale tasks.

![WCD Logo](assets/logo.png)

## ✨ Features

- 🎲 **Random Task Generator** — ek click me naya task
- 🗂️ **6 Categories** — Masti, Creative, Dimag, Fitness, Dare, Seekho
- ⏱️ **Time Filters** — 5, 15 ya 30 minute ke tasks
- ⏲️ **Built-in Timer** — har task ke saath countdown timer
- ⚡ **XP & Levels** — task poora karo, XP kamao, level up karo
- 🔥 **Daily Streaks** — roz khelo, streak banao
- 📜 **History** — apne kaarname dekho
- 💾 **Auto-save** — sab kuch browser me save rehta hai (localStorage)
- 📱 **Mobile-friendly** — phone pe ekdum mast chalta hai

## 🚀 Chalane ka tareeka

Koi install nahi chahiye — sirf `index.html` kholo:

```bash
# Option 1: seedha browser me kholo
open index.html        # Mac
start index.html       # Windows

# Option 2: local server (recommended)
python3 -m http.server 8000
# phir browser me kholo: http://localhost:8000
```

## 🌐 GitHub Pages pe live karo

1. Ye repo GitHub pe push karo
2. Repo Settings → Pages → Source: `main` branch, `/ (root)` → Save
3. Kuch second me app live: `https://<username>.github.io/wcd/`
